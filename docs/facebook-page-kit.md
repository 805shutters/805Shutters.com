## 3. Ongoing rhythm

- 2–4 posts/week; every finished install = one post (photo + city + one detail).
- Reply to every comment and message fast — the page's response-time badge matters.
- Join local groups (Camarillo/Moorpark/Thousand Oaks community & recommendation
  groups) as the Page where allowed; answer window-treatment questions helpfully,
  no hard selling.
- NEVER use the "Boost post" button — when ads start, they run from Ads Manager
  (see the 60/30/10 plan in the agency-research notes).
- Ask happy install customers for a Facebook recommendation as well as the Google
  review (the automated Google-review text already goes out via the CRM).
