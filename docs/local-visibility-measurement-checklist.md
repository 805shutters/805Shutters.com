# 805 Shutters local visibility measurement checklist

This is a free, owner-controlled review routine for the service-area business. It is a measurement checklist, not a request to create duplicate listings, buy ads, solicit reviews, or publish unsupported information.

## Weekly (10 minutes)

1. Search Google Maps and Bing for `805 Shutters`, `805 Shutters Camarillo`, and one real service query such as `plantation shutters Camarillo`. Record the visible business name, phone, website, category, hours, service-area presentation, and any incorrect public address.
2. Check the Google Business Profile and Bing Places dashboards for pending edits, verification notices, search/Maps views, and customer actions. Do not accept owner certifications or publish unreviewed edits as part of this check.
3. Check Yelp for Business for address, phone, website, hours, category, and any new photos or messages. Keep the business listed as a service-area operation; do not add a residential storefront address.
4. Confirm `https://www.805shutters.com/robots.txt` and `https://www.805shutters.com/sitemap.xml` return successfully. Check one service page and one city page for the correct canonical URL and consultation link.

## Monthly (30 minutes)

1. Record Google Business Profile calls, website clicks, direction requests (if shown), and search terms; record Bing Places views/actions and Yelp page views/leads separately. Do not combine provider metrics as if they were the same event.
2. Compare the three listings with the site source of truth:
   - 805 Shutters
   - (805) 806-9344
   - https://www.805shutters.com/
   - Mon-Sat, 8 AM-6 PM
   - Service-area business serving Camarillo and Ventura County; no public residential street address
3. Add only a newly completed, rights-cleared project photo when its product, room, and service-city context are known. Use factual filenames and captions; do not reuse stock imagery as a completed local project.
4. Review the site audit outputs when available: `npm run audit:site`, `npm run audit:llm-search`, and `npm run audit:seo-scorecard`. Fix broken canonicals, blocked crawl paths, missing structured-data fields, or inconsistent local facts before adding new location pages.

## Change controls

- A pending Google, Bing, Yelp, or Apple verification/attestation is an owner action, not routine maintenance.
- Never create a second listing for the same 805 Shutters service-area business.
- Never add a city page, category, service, photo, review response, Q&A, or business claim without direct supporting evidence.
- Keep paid ads and boosts outside this checklist; they require a separate campaign and spend approval.
