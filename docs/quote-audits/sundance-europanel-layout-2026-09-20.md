# Sundance measured Europanel layouts

Implemented optional versioned per-panel records for the exact Sundance and Louvolite Europanel destinations. A created layout contains the selected two to five unique panel identities; each width and height starts blank. Optional channel assignments refer only to the selected four- or five-channel track. Staff can retain factory layout notes internally. Product/fabric/opening changes mark existing layouts stale until the entered measurements are explicitly reconfirmed. Malformed records, count mismatches, duplicate identities, nonpositive measurements and out-of-track channel numbers block validation in both the visible component and saved server selection. Customer details show physical panel sizes/channel assignments without internal IDs or notes.

Sources: `C-Sundance-Europanels-V2.pdf` PDF15 and `F-Louvolite-Europanels-V2.pdf` PDF8, effective August1,2024. These specify left/right two-to-five-panel stacks and four/five channels, but do not provide numeric overlap, panel-width deduction or a complete panel-to-channel compatibility formula. The model therefore preserves entered dimensions, does not divide the opening width, does not force panel widths to sum to opening width, does not assume one panel per channel, and does not treat entered layouts as factory-approved or customer-price eligible. A layout is optional for existing held drafts; once present it must be internally complete. Current account and factory feasibility review remain required.
