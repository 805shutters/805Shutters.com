## Required source rules

- Never reuse generic Norman/Lotus product IDs, dealer factors, cost-plus margins, or six-inch assumptions. Use the next actual source header on each axis.
- Sundance cellular Bamboo Print LF is contradictory between I-3 and I-8; hold it until resolved. Cordless, TD/BU, day/night and cordloop each have different I-12 minimum/maximum dimensions.
- Horizontal J-7/J-12/J-13 have product-specific minima; grid availability further restricts dimensions. Chateau widths over 84 inches require split blinds; do not charge one unit for a split assembly.
- Walden Select grids include a separate valance-only row. The importer stops before that row, so it cannot become a smaller-height shade price.
- Vertical Essence has a 97.5-inch row and a separate vanes price column. Vanes are not width headers.
- C-10 and C-14 have nearly-rotated Height glyphs that confuse text extraction. Only complete numeric rows are accepted, with the rotated glyphs excluded by their transform.
- Do not activate shutters from their framed-area formula alone: rates/minimums/rounding remain missing. Exterior sheets are net-only and require a customer-selling policy.
